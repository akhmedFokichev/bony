# Geduko Live Analytics

Небольшой дашборд для разбора заезда на трассе Гедуко. Живые данные идут с [Kart Chrono](https://geduko.kartchrono.com/).

## Что показывает

- таблица текущего заезда: позиция, лучший/последний круг, отставание, сектора
- стабильность, теоретический круг, разброс и средний темп последних трёх кругов
- график темпа всех пилотов
- архив прошедших заездов

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес Vite (обычно `http://localhost:5173`). Live-тайминг и архив проксируются через `/kc-ws` и `/kc`, потому что Kart Chrono принимает сокет только со своего origin.

Для production:

```bash
npm run build
npm start
```
